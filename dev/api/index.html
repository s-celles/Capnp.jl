Capnp.BufferMessageBuilder — Type
BufferMessageBuilder <: Writer

Zero-allocation message builder that writes directly to a pre-allocated buffer. Does not allocate new segments - all data must fit in the provided buffer.

Usage

buffer = zeros(UInt8, 4096)
builder = BufferMessageBuilder(buffer)
# ... build message ...
bytes_written = finalize!(builder)
# buffer[1:bytes_written] contains the message

Notes

  • The buffer must be large enough to hold the entire message
  • If the message exceeds buffer capacity, an error is thrown
  • Use finalize!(builder) to get the number of bytes written
source
Capnp.BufferMessageReader — Type
BufferMessageReader <: Reader

Zero-copy message reader that operates on pre-allocated byte buffers. Uses views into the provided buffer instead of copying data.

Both message readers enforce traversal_limit_words across repeated pointer reads and nesting_limit along each followed struct/list pointer path. A limit violation raises InvalidMessageError.

Usage

bytes = read("message.bin")
reader = BufferMessageReader(bytes)
# Access data without copying

Capnp.apply_default_xor — Method
apply_default_xor(value::T, default::T) where T

Apply XOR decoding to retrieve the actual value from a wire value and its default. For reading: actual = wirevalue XOR defaultvalue

Example

# Field with default 42, stored as 0 on wire -> actual value is 42
apply_default_xor(UInt32(0), UInt32(42)) == 42

# Field with default 42, stored as 42 on wire -> actual value is 0
apply_default_xor(UInt32(42), UInt32(42)) == 0

Capnp.encode_with_default — Method
encode_with_default(value::T, default::T) where T

Apply XOR encoding to prepare a value for writing to wire format. For writing: wirevalue = valuetowrite XOR defaultvalue

Example

# Writing value 0 with default 42 -> stores 42 on wire
encode_with_default(UInt32(0), UInt32(42)) == 42

# Writing value 42 with default 42 -> stores 0 on wire (compact!)
encode_with_default(UInt32(42), UInt32(42)) == 0
